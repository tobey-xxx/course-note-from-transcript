# 成品片段示例

下面是同一段内容的三种写法，用来说明这个 skill 到底在改什么。

---

## 场景：讲师讲「商誉在新旧准则下的处理差异」

### ✗ 反面一：按时间复述（最常见的失败）

> 老师首先讲了商誉是怎么产生的，说商誉是合并中支付超过可辨认净资产公允价值的差额。然后老师问大家商誉在以前的会计处理中是怎么做的，有同学回答说是摊销。老师说是的，以前要估计摊销年限，比如 20 年、40 年。然后老师又问现在怎么处理，同学回答是资产，老师说对，现在不摊销了，只做减值测试。老师还举了个例子，说如果 200 万的商誉后来业务不行了，可能减 100 万。

问题：信息全在，但读者拿不走任何东西。这是转写的"缩写版"，不是笔记。

---

### ✗ 反面二：概念罗列（第二常见的失败）

> **商誉**
> - 定义：合并成本超过被购买方可辨认净资产公允价值的差额
> - 旧准则处理：摊销
> - 新准则处理：减值测试
> - 减值因素：业绩承诺未实现、行业变化

问题：像百科词条。读者知道"有这回事"，但不知道"什么时候该用哪套逻辑"。

---

### ✓ 正面：这 skill 的写法

#### 3.2 一个例子讲透：商誉

教师用商誉把两种观点摆在一起，这是全场最清晰的一个对照。

**收入费用观下：商誉要摊销。**

收购一家公司，可辨认净资产公允价值 800 万，你付了 1,000 万，200 万是商誉。在收入费用观下，这 200 万被视为「会被消耗掉的资源」，于是要和未来期间的收入匹配——所以**估计一个年限，逐年摊销**。

> 「就跟你固定资产差不多嘛，固定资产你不也得折旧吗？」

**资产负债观下：商誉不摊销，只做减值测试。**

现在的处理是：商誉挂在资产上，每年做一次减值测试。收购的标的干得好、业绩承诺兑现，商誉维持不变；标的没干好、业绩承诺没实现，说明价值没那么高，就计提减值。

| | 收入费用观 | 资产负债观 |
|---|---|---|
| 商誉是否摊销 | 是，估年限摊 | 否 |
| 每年动作 | 按摊销计划计提 | 减值测试 |
| 利润影响 | 平滑、可预期 | 平时为零，暴雷时一次性砸下来 |
| 主观性 | 摊销年限（10 年？20 年？40 年？）**极强** | 公允价值（有市场参照） |

#### 3.3 为什么要转过去：监管方的理由

改革是**准则制定方推动**的，理由是「对投资者最好、对企业也最好」。

以商誉为例，监管方的论证很朴素：

> 「你到底多少是这个今年的费用？你就要对摊销的年限进行很多假设——摊 10 年、20 年、30 年、40 年？这些假设好像是匹配了，但主观性很强，所以你为了匹配得出来的数字，也未必是真实的。」

反过来，资产负债观下**几乎没有假设**：看当下市场的公允价值，用资产（或负债）的价值反推你应该承担多少损益，「永远是平的」。

这也顺手解释了上午讲的小米可转换可赎回优先股：那个东西被界定为**负债**，公允价值每一期都在变，企业「其实啥也没干」，但负债价值一变就要调，对倒出来的就是当期损益。这就是资产负债观。

## 这个片段用到了哪些手法

| 手法 | 体现 |
|---|---|
| 主线服务 | 全段围绕「收入费用观 → 资产负债观」，不是孤立讲商誉 |
| 对比表格 | 四个维度：是否摊销 / 每年动作 / 利润影响 / 主观性 |
| 讲师原话 | 两处引用，都是有判断、有态度的句子 |
| 保留土办法 | 「跟固定资产差不多嘛，不也得折旧吗」原样保留 |
| 承接前文 | 「顺手解释了上午讲的小米」——把两场课串成一条线 |
| 判断标准 | 不是罗列"商誉是什么"，而是给出"什么时候会减值"的判据 |
| 数字带口径 | 800 万 / 1,000 万 / 200 万，构成可验算的关系 |

## 再看一个"课堂互动"的写法

### ✗ 只写结论

> 报表上的收入确认和现金回收没有直接关系，考核口径才看回款。

### ✓ 写出纠正过程

#### 9.1 业务和财务对「实现」的认知差

教师抛出的问题：**财务一定要等现金到账才确认收入吗？**

现场出现了三种回答，恰好拼出了三套不同的报表口径：

| 口径 | 依据 | 用途 |
|---|---|---|
| **法定报表（法报）** | 会计准则：控制权转移即确认 | 对外披露、监管 |
| **经营报表** | 企业自身管理要求（如 sell-in / sell-out 双口径） | 内部经营分析 |
| **绩效考核口径** | 董事长 / 高管的管理诉求（如回款才算业绩） | 考核业务人员 |

> 「对外有一套，对内有一套。这不是说两套账，这就是需要如此。」

教师的判断很清楚：**报表上的收入确认和现金回收没有直接关系**；但管理维度上关系极大——「董事长说，光有数没有钱，那是不行的」。

为什么后者更好：学生的直觉往往是大多数人的直觉。「财务是不是要等钱到账」这个问题，绝大部分人第一次都会答错。把"为什么错"写出来，读者才真的记住；只写正确结论，读者点个头就过去了。
