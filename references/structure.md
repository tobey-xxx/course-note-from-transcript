# 结构模板

## 整体骨架

```text
# 课程名 · 专题名（上午场 / 下午场）

**课程名称** / **授课教师** / **时间** / **地点** / **助教** / **本场内容**

> 导语段一：本场主线（一句话论点）
> 导语段二：与前后场次的关系
> 导语段三：讲师的方法论立场

---

## 一、开场或背景（为什么这个问题值得讲）
## 二、旧世界是什么样的（问题在哪）
## 三、范式转移 / 核心框架（分水岭）
## 四、框架总览（先给地图）
## 五 ~ 十四、逐步展开（每节一个判断标准 + 一个例子）
## 十五、现实冲击 / 案例（把理论砸到具体公司上）
## 十六、要点回顾（20–35 条编号）
## 附：人物与案例索引（表格）
> 笔记说明（数据口径与存疑标注）
```

---

## 逐块写法

### 头部元信息

```markdown
**课程名称**：财务会计（80517822）
**授课教师**：王琨（本场主讲；罗婷负责上周的整体框架）
**时间**：2026-11-07（周六）下午 14:00–16:40
**地点**：深圳 · 学思楼 C3-201
**课程助教**：朱绪娅
**本场内容**：收入准则的改革动因、五步法逐步拆解、总额法与净额法、
新租赁准则、使用权资产与租赁负债、国泰航空案例
```

要点：
- 授课教师有分工就写清分工（"某位讲框架、某位讲专题"）
- 时间写到分钟，方便日后找录音对应
- 「本场内容」用 5–8 个关键词短语，不要写成完整句子

### 导语（必须有，不要省）

用引用块写 2–4 段，交代三件事。**这是全篇最该花力气的地方**，因为它决定了读者要不要往下读。

```markdown
> **本场的主线**：上午讲的是「会计怎么把未来可能发生的事提前装进今天的报表」；
> 下午这两个准则讲的是同一件事的另一个侧面——**报表的锚点从利润表挪到了资产负债表**。
>
> 教师反复用一句话概括这次全球改革：「从**收入费用观**转向**资产负债观**」。
> 收入准则如此（先看资产负债的价值，再反推收入），租赁准则也如此。
> 理解了这条主线，两个准则的具体条文都是从它长出来的。
```

三种常用导语组合：

| 场景 | 导语该写什么 |
|---|---|
| 系列课中的一场 | 承接了什么 + 为下一场铺垫了什么 |
| 单场独立讲座 | 这个问题为什么现在重要 + 讲师的核心立场 |
| 有新旧对比的课 | 旧的错在哪 + 新的解决了什么 + 代价是什么 |

### 正文分节

**节标题写成判断句或问题，不是名词。**

| 差 | 好 |
|---|---|
| 收入准则的改革 | 旧准则的两个词：earned 和 realized |
| 租赁会计处理 | 新租赁准则：要解决的是表外融资 |
| 履约义务 | 第二步：识别单项履约义务——质保到底拆不拆 |
| 案例介绍 | 国泰航空：一次准则变更，三张表全动 |

每节内部用 `###` 拆到 2–4 个小节。每个核心概念配四件套：

```text
定义（一句话）
  → 判断标准（遇到什么情况、按什么标准）
  → 例子（最好是讲师给的原始例子）
  → 一句话结论
```

### 讲师原话

用 `>` 引用块。选句标准：

| 该选 | 不该选 |
|---|---|
| 有判断的："这不就正对嘛" | 过渡句："我们今天讲第三章" |
| 有立场的："我不觉得这是空子" | 纯复述："刚才我们说到了……" |
| 有现场感的："我天天讲就讲" | 口头禅填充："对不对""是吧" |

引用后可以补一句解读，但**不要改写原话**。

### 课堂互动

单独成小节，保留三要素：**谁说的 + 说了什么 + 讲师怎么接**。

```markdown
### 9.2 渠道压货：一个公开的秘密

现场有同学（做过审计、也在企业待过）把行业实况讲得很直白：

> 「到了年底的时候就是会让供应商多压点货，然后我们把收入做得高一点，
> 明年大不了以退货的形式再给我。这个很普遍。」

教师没有道德批判，而是把它放进「三位一体」的框架：
先承认动机客观存在 → 再算后果（股东会告你）→ 最后落到均衡。
```

真实企业的做法往往比理论更值钱，**不要删**。

### 要点回顾

20–35 条编号短句。要求：

- 每条一行、可独立成立、可直接背诵
- 是**结论**不是**目录**（"旧准则只有两个词：earned 和 realized" ✓；"讲了旧准则" ✗）
- 不要按节复述，要跨节提炼

### 附录：人物与案例索引

三列：名称 / 出现位置 / 要点。方便日后检索。

```markdown
| 名称 | 出现位置 | 要点 |
|---|---|---|
| Ross Watts | 十五 | 会计保守主义的理论源头 |
| 国泰航空 | 十四 | 78 架经营租赁飞机入表，三张表同时受影响 |
```

### 笔记说明

一段话交代四件事：

1. 转写来源：时长、段数、字数
2. 数字口径：哪些按口述、哪些按上下文反算、差异在哪
3. ASR 校正记录：原词 → 校正词
4. 存疑处：哪些地方未展开、哪些无法还原

**这不是免责声明，是可信度的来源。** 明确区分"讲师说的""我推算的""听不清的"，读者才敢引用。

## 篇幅控制

| 课程时长 | 字数 | 行数 | 节数 |
|---|---|---|---|
| 1.5 小时 | 1.2–1.6 万 | 500–650 | 9–13 |
| 2 小时 | 1.8–2.2 万 | 700–900 | 12–18 |
| 3 小时 | 2.6–3.2 万 | 1000–1300 | 16–22 |

明显短于下限说明漏了内容，明显长于上限说明在注水。
