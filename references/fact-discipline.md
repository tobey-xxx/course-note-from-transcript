# 事实纪律：防编造的五个约束

光说"不要编造"没有用。必须给**可执行的负向规则**。

---

## 约束 1：引用必须可定位

每条 `>` 引用都要能指回某个时间戳。

**自检方法**：写完后随机抽 3 条引用，回原文搜关键词，看是否真的存在、是否被改写。

**高危模式**：模型喜欢造"金句"——一句听起来很有道理、结构工整的话。凡是你觉得"这句话说得真好"的引用，优先核对。

---

## 约束 2：数字必须可反算

凡是能通过其他数字推算的，都算一遍。不一致就标注，不要二选一。

| 可反算关系 | 例子 |
|---|---|
| 利润率 = 利润 / 收入 | 讲师说收入 100、利润 20，又说利润率 25% → 矛盾，标注 |
| 合计 = 各分项之和 | 三项单独售价合计 150，分摊总价 100 → 验算占比 |
| 现值 = 年金 × 现值系数 | 80 万 × 5 年 10% 系数 3.7908 ≈ 303 万 |
| 变动额 = 新 − 旧 | 利润从 X 降到 Y，"少了 Z"要能对上 |

**不确定就用区间或量级**，不要给一个精确到小数点的假数。

---

## 约束 3：人名 / 公司名必须可还原

ASR 对专有名词的识别错误率极高。处理顺序：

1. **按上下文还原**（最常见）
2. **还原不了就写"某公司""某产品"**
3. **绝不音译成看似真名的词**

常见错法对照（真实案例）：

| 转写原词 | 应为 | 判断依据 |
|---|---|---|
| 花瑞世纪 | 欢瑞世纪 | 影视公司，A 股上市 |
| pesco / casio / festal | Tesco | 与 Ahold 对比语境 |
| a 后 / a home | Ahold | 同上 |
| 叶菜 | 业财 | "业财一体化" |
| 伊贝塔 | EBITDA | 财务指标语境 |
| 江阴股份 | 江铃汽车 | 教师自述任独董的公司 |
| 学 / 虎敲鼓 | Keurig | 咖啡机品牌 |

**注意**：教学场景下讲师可能自己说错公司名，这时保留讲师原话并标注，不要替他改。

---

## 约束 4：区分说话人

讲师 / 学生 / 嘉宾的判断不能混。

| 情形 | 写法 |
|---|---|
| 学生提出观点 | 「现场有同学提出：……」 |
| 讲师认可 | 「教师确认这个观察成立」 |
| 讲师否定 | 「学生的观点是 X，讲师纠正为 Y」 |
| 讲师转述他人观点 | 「教师引用了某学者的观点：……」 |

**高危模式**：把学生的行业经验写成讲师的结论。学生说的往往是"我们公司怎么做"，这是案例，不是准则。

---

## 约束 5：矛盾不擅自统一

讲师口述和幻灯片/板书不一致时，**两个都保留**。

**差**：「补提 14.6 万。」（擅自选了看起来更准的那个）
**好**：「（课堂口述约 14 万，按进度重算约 14.6 万）」

**差的另一种**：「补提约 14 万。」（擅自选了讲师说的，掩盖了矛盾）

正确做法是让读者知道这里有分歧，并知道他该信哪个、为什么。

---

## ASR 校正的边界

| 该校正 | 不该校正 |
|---|---|
| 明显的同音错字（业财 / 叶菜） | 讲师的个人用语习惯 |
| 专有名词（公司、人名、产品） | 讲师故意用的口语比喻 |
| 断句与标点 | 讲师的重复强调（"很重要，很重要"） |
| 数字单位（万 / 亿 / 百万） | 讲师的自我修正（保留修正过程） |

**保留自我修正的例子**：

> 「这个数跟刚才不是衔接的，后边又找了一个新的数字作为例子，但财务处理是一样的。」

这种"讲师自己发现讲错了"的痕迹，对读者理解例题很有帮助，不要删。

---

## 转写质量分级与应对

| 等级 | 特征 | 应对 |
|---|---|---|
| A（可辨识 > 90%） | 少量错字 | 正常整理，标注个别存疑 |
| B（70–90%） | 有 MISSING、句子断裂 | 正常整理，存疑处密集标注 |
| C（50–70%） | 大量 MISSING、语义跳跃 | 只提炼骨架与要点，明说质量不足 |
| D（< 50%） | 无法还原语义 | 停止，告知用户需要更好的转写 |

**不要假装 D 级转写能整理出 A 级笔记。** 那必然导致编造。
