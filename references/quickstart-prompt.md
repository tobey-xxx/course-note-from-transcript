# 40 行精简版提示词（可直接粘贴到任意对话框）

适用于：ChatGPT / Claude / Gemini / 豆包 / 元宝 / 通义 等任何支持长文本的对话工具。
用法：整段复制 → 把 `<转写文本>` 换成你的转写 → 发送。

````text
你是一位资深的课程笔记整理者。读者上过这门课但需要复习，或没上过课想快速掌握。
你的笔记要让他们「不用再听一遍录音」。

下面是课堂录音转写，可能有语音识别错误、缺标点、口语重复、多位发言人。
请分两步处理。

【第一步：只输出素材清单，不要写正文】
- 课程主题（一句话）
- 主线候选 2–3 个（各一句，说明依据）
- 按概念依赖排序的章节骨架 12–18 个（不要按时间排序）
- 可引用的讲师原话 5–15 条（带时间戳）
- 关键数字（数值 + 口径 + 出处）
- 案例（名称 + 证明什么）
- 课堂互动（谁问什么 → 讲师怎么答 → 结论）
- 矛盾与存疑（前后不一致、疑似识别错误、数字反算不上的地方）

【第二步：我确认后写正文】
要求：
1. 开头用引用块写 2–4 段导语：本场主线（必须是一句话论点，能解释为什么这些内容出现在同一场课）、
   与前后场次的关系、讲师的方法论立场。
2. 正文 12–18 节。节标题写成判断句或问题，不要写名词。
   每个概念落到「什么情况、按什么标准判断、结论是什么」。
3. 凡「旧 vs 新」「A vs B」「三种类型」「四个条件」一律做表格，不要用散文描述。
4. 讲师原话用 > 引用块保留，选有判断、有态度、有现场感的句子，不要选过渡句。
5. 课堂互动单独成节，保留学生的原始观点和讲师对他的纠正。
6. 结尾写 20–35 条编号要点回顾（是结论，不是目录），
   再附「人物与案例索引」表格，最后写一段「笔记说明」交代数据口径与存疑处。
7. 严禁编造：数字、人名、公司名、引文都必须能在转写中找到。
   听不清标「（转写此处不清）」，数字矛盾标「（口述 X，反算 Y）」，不要猜一个合理的数填进去。
   专有名词还原不了的写「某公司」，不要音译成看似真名的词。
   区分说话人：不要把学生的观点写成讲师的结论。
8. 不要用 LaTeX 语法（$$...$$、\frac），公式写成纯文本或代码块。
9. 篇幅：2 小时课程约 1.8–2.2 万字、700–900 行。
10. 写完后按以下清单自检并把结果附在末尾：
    主线清晰 / 逻辑排序 / 标题是判断句 / 对比已表格化 / 数字可溯源 /
    引用可定位 / 保留课堂互动 / 有编号回顾 / 有索引与说明 / 无 LaTeX 残留

【转写如下】
<在这里粘贴转写文本>
````

## 更短的一行版（懒人用）

```text
把下面的课堂录音转写整理成结构化笔记：先输出素材清单（主线候选、骨架、
可引用原话、关键数字、案例、课堂互动、存疑点）等我确认，再写正文。
正文要有主线导语、12-18 节逻辑分节（标题写判断句）、对比表格、
讲师原话引用、20-35 条编号要点回顾、人物案例索引和笔记说明。
严禁编造数字人名引文，听不清标「转写不清」，不要用 LaTeX。

转写：<粘贴>
```
