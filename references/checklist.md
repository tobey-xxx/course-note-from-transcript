# 质检清单

写完逐条打勾，附在回答末尾。不要把清单当免责声明——发现不合格要改。

---

## 内容层

- [ ] 主线能用一句话说清，且正文每一节都在服务这条主线
- [ ] 导语交代了三件事：主线、与前后场次的关系、讲师的方法论立场
- [ ] 所有数字都能在转写里找到出处，或已标注推算方式
- [ ] 引用的讲师原话至少 8 条，且都能在转写中定位
- [ ] 课堂互动至少保留 2 处，包含学生的原始观点
- [ ] 讲师与学生的观点没有混用
- [ ] 存疑处已明确标注（转写不清 / 口述与反算不一致 / 无法还原的专名）
- [ ] 没有编造任何数字、人名、公司名、引文

## 结构层

- [ ] 章节顺序是逻辑顺序，不是时间顺序
- [ ] 全文没有出现"00:00–15:00 讲师介绍了……"式的分节
- [ ] 每节标题是判断句或问题，不是名词
- [ ] 每节至少落到一个"判断标准"，不只是概念罗列
- [ ] 有编号的要点回顾，20–35 条
- [ ] 要点回顾是结论，不是目录（不重复节标题）
- [ ] 有「人物与案例索引」表格
- [ ] 有「笔记说明」段落

## 排版层

- [ ] 对比类内容都做成了表格（「旧 vs 新」「A vs B」「三种类型」「四个条件」）
- [ ] 表格比较维度不全是"是/否"
- [ ] 讲师原话用引用块，且选的是有判断的句子
- [ ] 关键结论有加粗，但不过度（一屏最多 3–4 处）
- [ ] 没有 LaTeX 残留：搜索 `$$`、`\frac`、`\text` 应为 0
- [ ] 公式用纯文本或代码块
- [ ] 段落短，一句一段为主

## 篇幅层

- [ ] 字数在区间内（2 小时课：1.8 万–2.2 万字）
- [ ] 行数在区间内（2 小时课：700–900 行）
- [ ] 二级标题 12–18 个
- [ ] 后 1/3 与前 1/3 详尽度相当，没有明显衰减

---

## 验收指标速查

| 指标 | 1.5 小时 | 2 小时 | 3 小时 |
|---|---|---|---|
| 字数 | 1.2–1.6 万 | 1.8–2.2 万 | 2.6–3.2 万 |
| 行数 | 500–650 | 700–900 | 1000–1300 |
| 二级标题 | 9–13 | 12–18 | 16–22 |
| 表格 | 10–18 | 15–25 | 22–35 |
| 讲师引用 | 6–15 | 8–20 | 12–28 |
| 编号要点 | 15–25 | 20–35 | 28–45 |
| LaTeX 残留 | 0 | 0 | 0 |

**结构指标是质量的先行指标**：字数够了但表格只有 3 个，基本可以肯定是在写散文而不是在整理知识。

## 八种失败模式对照

| 症状 | 根因 | 修法 |
|---|---|---|
| 读完像流水账 | 按时间顺序写 | 强制按概念依赖排序，禁止时间戳分节 |
| 全是知识点，串不起来 | 没定主线 | 回第一步输出主线候选并说明取舍 |
| 内容空泛、像百科词条 | 只写"是什么"，没写"怎么判" | 每个概念补"判断标准"和"例子" |
| 有数字但不敢信 | 编造 | 凡可反算的都算一遍，不一致标注 |
| 引用不真 | 造金句 | 抽查 3 条回原文搜 |
| 后 1/3 明显变短 | 长上下文衰减 | 先写后半部分，或分段写再拼 |
| 排版一坨 | 没用表格和引用块 | 结构模板里写死"对比必须表格化" |
| 结尾突然收住 | 没有回顾节 | 强制 20–35 条编号要点 |

---

## 交付时说什么

三句话以内：

1. 笔记写到哪、多少字多少节
2. 有几个存疑点、分别是什么
3. 做了哪些 ASR 校正

不要把质检清单逐条念出来，只报结论性信息。
