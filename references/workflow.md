# 工作流程详解

## 为什么必须两遍

一次 prompt 直接要终稿，模型会为了"填满结构"而编造。分成两遍：

1. **第一遍**只要素材清单。清单本身可核对——你能一眼看出它哪里读错了、哪里漏了，改完再写，成本低。
2. **第二遍**基于清单写正文。此时模型只能从清单取料，编造空间被压缩。

如果模型上下文窗口小、吃不下一整份转写，就**分段读、分段出清单，最后合并再写正文**。

---

## 第一步：通读并出清单

### 硬性要求

- 必须读完，不能只读开头和结尾。判断依据：能列出 5 条以上带时间戳的原话。
- 清单里每条都要能指回原文位置。
- 不要在这一步写任何段落式正文。

### 清单模板

```text
【素材清单】

课程主题（一句话）：
  ___

主线候选（2–3 个，各一句，注明依据）：
  A. ___  依据：___
  B. ___  依据：___
  C. ___  依据：___

结构骨架（按概念依赖排序，8–18 个节点，不按时间）：
  1. ___
  2. ___
  ...

可引用的讲师原话（5–15 条）：
  [时间戳] "原话" —— 用途：___

关键数字（数值 + 口径 + 出处）：
  数值 ___ | 口径 ___ | 出处 [时间戳]

案例（名称 + 证明什么）：
  名称 ___ | 证明 ___ | 出处 [时间戳]

课堂互动（谁问什么 → 讲师怎么答 → 结论）：
  [时间戳] 提问者：___ → 讲师：___ → 结论：___

矛盾与存疑：
  - [时间戳] 讲师口述 ___，但按 ___ 反算应为 ___（保留两者）
  - [时间戳] 疑似 ASR 错误：___ → 推测为 ___
  - [时间戳] 此处转写残缺，无法还原
```

### 怎么找主线

主线不是"这节课讲了 X 和 Y"，而是**一个论点**。三种常见形态：

| 形态 | 例子 | 适用 |
|---|---|---|
| **范式转移** | 「两个准则的共同内核是从收入费用观转向资产负债观」 | 有新旧对比、有改革背景的课 |
| **一个问题的多个侧面** | 「整场只讲一件事：会计怎么把未来可能发生的事提前装进今天的报表」 | 有明确分析框架的课 |
| **一条判断标准贯穿** | 「所有判断最后都落到『风险在谁身上』」 | 案例密集、方法论导向的课 |

判断标准：**这个论点能不能解释"为什么这些看起来不相关的内容会出现在同一场课里"？** 不能，就不是主线。

### 怎么排序骨架

不要按时间。按**概念依赖**：读者理解第 N 节，需要先知道什么。

一个稳健的默认顺序：

```text
背景/问题为什么值得讲
  → 旧世界是什么样的（问题在哪）
  → 转折点/核心框架（分水岭）
  → 框架总览（先给地图）
  → 逐步展开（每步一个判断标准 + 一个例子）
  → 砸到具体案例上（现实冲击）
  → 收口
```

---

## 第二步：定主线并说明取舍

输出一小段：

```text
选定主线：___
理由：___
放弃的候选及原因：___
因与主线无关而压缩/舍弃的内容：___
```

这一步的价值是**逼自己承认删了什么**。不写这一段的笔记，通常什么都舍不得删，最后变成全量复述。

---

## 第三步：写正文

按 `structure.md` 的模板。三个执行要点：

1. **先写导语**。导语写不出来，说明主线还没定，回第二步。
2. **每节先写结论句，再展开**。结论句放节首，读者扫标题 + 首句就能决定要不要细读。
3. **写完一节检查一次**：这节有没有落到"判断标准"？只有定义没有判断标准的，补一个。

---

## 第四步：自检

按 `checklist.md` 过一遍。发现不合格，改完再交付，不要把清单当免责声明。

---

## 常见返工点

| 现象 | 说明 | 修法 |
|---|---|---|
| 后 1/3 明显变短、变敷衍 | 长上下文自然衰减 | 先写后半部分，或分段写再拼 |
| 引用不真 | 模型自己造金句 | 抽查 3 条引用，回原文搜 |
| 数字对不上 | 顺手算错或编造 | 凡可反算的数字都算一遍 |
| 前半段有主线，后半段跑偏 | 骨架没定死 | 回第二步重排骨架 |
| 表格里全是"是/否" | 比较维度没想清 | 换维度：机制 / 影响 / 主观性 / 谁承担 |
